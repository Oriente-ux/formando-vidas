# Imagens do site

Esta pasta contém as fotografias usadas no site (galeria, mural e notícias).

## Como adicionar as imagens (upload manual)

1. Abra esta pasta no GitHub: https://github.com/Oriente-ux/formando-vidas/tree/main/assets/img
2. Clique em **Add file** → **Upload files**
3. Arraste os 9 arquivos `.jpeg` de `C:\Users\valde\Documents\Programação Html Css\assets\img`
4. Escolha **Commit directly to the main branch** e confirme
